# TASOS

TASOS is a from-scratch operating system project targeting the x86_64 architecture.

The project is being developed through project-based learning, with each operating-system concept introduced only when required by a working feature.

## Initial Goals

- Boot on x86_64 through GRUB
- Enter a freestanding C kernel
- Display text through a kernel terminal
- Handle CPU exceptions and hardware interrupts
- Read keyboard input
- Manage physical and virtual memory
- Support processes, scheduling and system calls
- Implement a filesystem and user-space shell
- Add graphics, networking and hardware drivers

## Development Environment

- Windows 11
- WSL2
- Ubuntu 24.04 LTS
- GCC
- NASM
- GNU Make
- GNU GDB
- GRUB
- xorriso
- QEMU

## Current Status

Development environment configured and validated.

TASOS is not bootable yet.

## Target Architecture

- Initial: x86_64
- Possible future target: ARM64
